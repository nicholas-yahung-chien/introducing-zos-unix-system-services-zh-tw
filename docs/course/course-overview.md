# z/OS UNIX 課程概觀

本單元建立 z/OS UNIX System Services 的整體定位，說明 UNIX 標準、z/OS 上的 UNIX 實作，以及 z/OS UNIX 元件在大型主機環境中的角色。

## 學習脈絡

z/OS UNIX 讓 z/OS 能提供符合開放標準的 UNIX 介面，同時保留大型主機的安全、可靠性與資料處理能力。先理解標準與實作方式，後續 shell、檔案系統與程序管理才會有穩定脈絡。

## 本章目標

- 說明 z/OS UNIX 與 UNIX 標準的關係。
- 理解 porting UNIX 應用到 z/OS 時需要注意 ASCII 與 EBCDIC。
- 辨識 z/OS UNIX 中常見的 file system 類型。

## 觀看順序

- UNIX 標準入門
- z/OS 上的 UNIX 實作
- z/OS UNIX 元件
