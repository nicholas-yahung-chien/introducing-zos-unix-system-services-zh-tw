# z/OS UNIX shell 與 utilities

本單元介紹 z/OS shell、TSO 與 shell 的關係，以及如何在 shell 中執行 commands、jobs 與 scripts。

## 學習脈絡

z/OS UNIX shell 是進入開放系統介面的主要入口。它可搭配 TSO、JCL 與 batch job 使用，讓傳統 z/OS 工作流與 UNIX 指令工具互相連接。

## 本章目標

- 說明 z/OS shell 的用途。
- 理解 TSO 與 z/OS UNIX shell 的互動方式。
- 辨識 shell script、background job、submit command 等工作模式。

## 觀看順序

- z/OS shell
- TSO 與 z/OS UNIX shell
- Commands 與 jobs
