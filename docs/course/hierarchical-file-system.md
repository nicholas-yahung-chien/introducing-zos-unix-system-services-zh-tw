# 階層式檔案系統

本單元深入 z/OS UNIX 的階層式檔案系統，涵蓋 HFS、zFS、directory、mount、ISHELL、ISPF 整合、備份復原、NFS 與 file security。

## 學習脈絡

傳統 z/OS data set 與 UNIX 階層式檔案系統並存。系統管理者與應用開發者需要知道檔案系統如何掛載、如何管理、如何保護，以及如何從 ISPF 或 ISHELL 操作。

## 本章目標

- 說明 HFS、zFS 與 z/OS UNIX 檔案系統概念。
- 理解 ISHELL、Directory List Utility 與 ISPF 如何操作 z/OS UNIX。
- 掌握備份復原、NFS 與 file security 的基本注意事項。

## 觀看順序

- 階層式系統入門
- 類型
- HFS 與 zFS data set 基礎
- HFS 與 zFS 檔案系統
- ISHELL 與 Directory List Utility
- Directory List Utility panels
- ISPF 與 z/OS UNIX
- 系統結構
- 備份與復原
- Network file system 與 file security
- Lab 環境熟悉
