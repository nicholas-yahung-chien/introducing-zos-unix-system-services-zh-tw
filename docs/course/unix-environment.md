# 使用 z/OS UNIX 環境

本單元收束到 z/OS UNIX 應用程式開發、printing、access control lists 與其他環境考量。

## 學習脈絡

當 shell、檔案系統與 process 概念建立後，學習者可以進一步理解 z/OS UNIX 應用程式如何編譯、啟動、列印與套用存取控制。

## 本章目標

- 知道可用哪些 utility 編譯 z/OS UNIX C++ source program。
- 理解 PDS 中 load module 的啟動情境。
- 認識 ACL、printing 與環境限制。

## 觀看順序

- z/OS UNIX 應用程式設計
- Printing 與 access control lists
- 其他考量
