# z/OS UNIX shell commands 指令

本單元整理常見 shell command、help、code page、environment variables 與 file system 資訊查詢。

## 學習脈絡

shell command 是 z/OS UNIX 的日常操作語言。學習時要同時注意 UNIX 語意與 z/OS 特有的 code page、EBCDIC、mount 與資料集整合。

## 本章目標

- 使用 help 查詢 shell command。
- 理解 environment variable 的設定方式。
- 知道如何顯示 file system 資訊。

## 觀看順序

- 取得說明與使用 code pages
- System shell commands
- 更多 shell commands
