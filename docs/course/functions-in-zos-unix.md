# z/OS UNIX functions 功能

本單元介紹 z/OS UNIX callable services、processes、daemons、superusers、child processes、communications 與 threads。

## 學習脈絡

z/OS UNIX 不只提供指令，也提供 runtime library 與 callable services。這些功能支撐程序建立、通訊、執行緒與 daemon 類服務。

## 本章目標

- 辨識 z/OS UNIX callable services 的 BPX prefix。
- 說明 daemon、superuser 與 login request listener。
- 理解 process、child process、address space 與 threads。

## 觀看順序

- Functions 與 processes
- Daemons 與 superusers
- Child processes
- Communications 與 threads
