# 詞彙選取紀錄

本課程詞彙表聚焦 JES/JCL、system programming、z/OSMF 與 USS。第一版收錄能直接支援章節頁、Lab metadata 與 H5P 練習題的詞彙。

## 主要類別

- JES / JCL：JES、JCL、JOB statement、MSGLEVEL、procedure。
- System libraries：LINKLIB、PROCLIB、PARMLIB、SYSRES、IODF。
- Runtime and data：Language Environment、compiler、VSAM、GDG。
- Platform services：RAIM、RACF、SAF、utilities。
- Modern interfaces：z/OSMF、REST API、USS、ISHELL、HFS、root directory。
