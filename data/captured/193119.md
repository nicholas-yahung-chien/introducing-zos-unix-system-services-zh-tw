### Highlights - z/OS UNIX Shell Commands

This unit discusses some of the more basic commands. Note: Commands here are not (z/OS) operator commands; commands here are solely related to the UNIX shell interface

After completing this unit, you should be able to:

- Work with command syntax

- INVOKE UNIX commands in shell

- Get help for a command

- Know more about file systems

- Define what a current directory is

- Move files from HFS
