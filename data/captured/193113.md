### Highlights - z/OS UNIX Shell and Utilities

After completing this unit, you should be able to:

- Identify the network support for z/OS UNIX shell

- Describe the relationship between TSO/E and the shell

- Explain the concept of shell user ids

- Describe how to invoke the shell

- List some of the ways a user can customize the shell

- Define the online help function

- Recognize ways to combine shell commands

- Describe the REXX support for z/OS UNIX

- Match shell functions to equivalent TSO functions
