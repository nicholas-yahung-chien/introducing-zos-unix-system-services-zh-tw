### Highlights - Hierarchical File System

After completing this unit, you should be able to:

- Describe the structure of the hierarchical file system

- Define the path name of a file

- List file types in the file system

- Describe different ways to identify HFS/zFS file

- Explain the concept of file permission bits

- Name the interfaces to access HFS/zFS file
